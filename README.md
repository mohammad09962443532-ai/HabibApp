# حبیب سازنده برنامه | Habib App Builder
اپلیکیشن آفلاین فارسی برای آموزش ساخت برنامه‌های اندرویدی، انتخاب قالب و ساخت طرح اولیه پروژه.

## امکانات نسخه اول
- دفترچه آموزش آفلاین برای بازی، فروشگاه، پیام‌رسان، موسیقی، ویدیو، ابزار، آموزشی، شبکه اجتماعی، رزرو و مالی
- انتخاب قالب و امکانات، تولید Project Blueprint
- ذخیره طرح به صورت JSON در پوشه Downloads/HabibBuilder و اشتراک‌گذاری
- رابط فارسی راست‌چین
- ساخت APK با GitHub Actions

> این نسخه طرح پروژه و راهنمای ساخت تولید می‌کند؛ هنوز پروژه قابل واردکردن مستقیم Sketchware Pro یا APK خودکار از هر نوع برنامه تولید نمی‌کند. برای واردسازی مستقیم باید قالب پروژه Sketchware مطابق نسخه هدف پیاده‌سازی و آزمایش شود.

## ساخت APK در GitHub
1. ZIP را باز کنید و همه فایل‌ها را به مخزن جدید GitHub آپلود کنید.
2. تب Actions را باز کنید و workflow با نام **Build Habib App Builder APK** را انتخاب کنید.
3. روی Run workflow بزنید.
4. پس از سبز شدن، Artifacts را باز و `Habib-App-Builder-debug-apk` را دانلود کنید.
5. ZIP آرتیفکت را باز کرده و APK را نصب کنید.

## ساخت محلی
با Android Studio و JDK 17: `gradle assembleDebug`
APK: `app/build/outputs/apk/debug/app-debug.apk`
